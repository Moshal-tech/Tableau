## 🌟 Project Overview

This project was completed as part of my **Data Technician Bootcamp**, focusing on using **Tableau and Tableau Public** to transform datasets into interactive dashboards, engaging visualisations and actionable insights.

The project strengthened my ability to explore data, identify patterns, compare performance and communicate findings through effective **data storytelling**.

I worked with datasets covering **employment, global health and demographic trends**, developing transferable analytical techniques applicable to retail and sales performance reporting.

## 🛠️ Tools & Technologies

- 🔵 **Tableau Public** – Dashboard development and publishing
- 🟢 **Microsoft Excel** – Source datasets
- 🟠 **Calculated Fields** – Custom metrics and analytical calculations
- 🟣 **Interactive Filters & Filter Controls** – Dynamic data exploration
- 🟡 **Charts & Maps** – Visual comparisons and geographical analysis

## 🚀 Key Skills Demonstrated

### 📊 1. Interactive Dashboard Development

- Created interactive dashboards combining multiple visualisations into a single reporting view.
- Applied filters and dashboard controls to explore specific countries, years and categories.
- Organised dashboard layouts to improve usability and communicate key information clearly.
- Published visualisations using Tableau Public.

### 📈 2. Data Visualisation & Chart Creation

Explored different chart types to communicate insights effectively:

- 📊 **Bar Charts:** Comparing performance across categories, countries and regions.
- 📈 **Line Charts:** Identifying changes and trends over time.
- 🥧 **Pie Charts:** Presenting population distributions and percentage contributions.
- 🗺️ **Maps:** Visualising geographical differences in employment and regional performance.
- 🔵 **Scatter Plots:** Exploring relationships between numerical measures.
- 🎨 **Treemaps:** Comparing industry contributions and relative category sizes.

### 🧮 3. Data Analysis & Calculated Fields

- Worked with dimensions and measures to structure Tableau visualisations.
- Explored calculated fields to support custom metrics and business analysis.
- Used aggregations and percentage-of-total calculations to interpret data.
- Applied sorting, Top N filters and interactive filter selections to investigate patterns.

### 🛍️ 4. Retail & Sales Analytics Applications

Applied visualisation principles relevant to commercial reporting, including:

- Comparing sales revenue across products and regions.
- Identifying top-performing and underperforming categories.
- Visualising sales trends and seasonal performance.
- Analysing geographical variations in customer demand.
- Designing dashboards that support performance monitoring and business decisions.

### 📖 5. Data Storytelling

- Transformed raw data into clear and visually engaging analytical reports.
- Selected appropriate chart types to communicate different business questions.
- Used colour, labels and dashboard layouts to make insights easier to interpret.
- Focused on presenting findings in a format accessible to non-technical stakeholders.
